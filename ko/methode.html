랭킹 방식

RebornRank는 테마 특화 작품 탐색 사이트입니다. 원본 데이터베이스를 대체하지 않으며, 필요할 때 데이터를 요청하고 호출을 줄이기 위해 로컬 캐시에 저장합니다.

표지는 데이터 출처가 제공하는 URL을 사용합니다.
각 카테고리는 시작 태그를 각각 검색한 뒤 결과를 합치므로 모든 태그를 동시에 가진 작품만 남는 문제가 없습니다.
여러 페이지를 탐색한 뒤 스토리 메커니즘 규칙을 적용합니다.
숨은 명작은 평점과 인기도 기준을 API 단계에서 적용해 유명작 밖까지 찾습니다.
성인 콘텐츠는 기본적으로 제외합니다.
Forgotten Source는 제작자 프로젝트로 순위 밖에 표시하며 가짜 평점이나 순위를 만들지 않습니다.
