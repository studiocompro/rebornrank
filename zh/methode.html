排行榜如何计算？

RebornRank 是一个按主题发现作品的网站，不替代原始数据库；数据按需请求并缓存在本地，以减少 API 调用。

封面使用数据来源返回的图片链接。
每个分类会分别查询各个起始标签并合并结果，因此作品无需同时拥有所有标签。
排行榜会扫描多页结果，再应用对应剧情机制的筛选规则。
冷门佳作直接使用评分和人气阈值，主动寻找知名作品之外的条目。
默认排除成人内容。
Forgotten Source 以创作者项目形式在榜外展示，不伪造评分或名次。
AniList

本站使用该数据源获取元数据与封面，并按需查询；本站不是该数据库的备份或镜像。
